# Example: Formula Review

## User setup

Provide the equation together with the surrounding manuscript text and, if relevant, the code that computes it.

Example request:

> Grill me on this equation until I can explain it to my advisor without relying on memorized wording.

## Expected behavior

The skill should verify that the user can explain:

- what problem the equation solves;
- every symbol;
- which terms are measured, estimated, optimized, assumed, or derived;
- why the mathematical form is appropriate;
- how it connects to the experiment;
- relevant limiting or edge cases;
- what the formula does and does not justify scientifically.

The skill should ask exactly one question per turn.
