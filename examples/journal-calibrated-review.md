# Example: Journal-Calibrated Review

## User setup

Provide the manuscript section and identify the target journal or conference.

Example request:

> My target journal is Nature Communications. Research the journal first, then grill me on this manuscript section as a plausible reviewer for that venue would.

## Expected behavior

Before substantive questioning, the skill should research the venue using current sources.

It should build a reviewer profile from evidence such as aims and scope, author guidelines, public editorial or reviewer criteria, recent comparable papers, and reporting or reproducibility expectations.

For interdisciplinary manuscripts, it should separate core contribution, supporting technical content, and peripheral domain content, then calibrate questioning depth accordingly.

After calibration, it should return to the one-question-at-a-time workflow.
